# stiles-theme

A collection of themes that I am currently using. This is the first edition of
it and will largely just contain gruvbox themes for each application I use by 
default.

In the future there may be changes and support for more applications that have
configurable themes added to this repository.

## Applications

- nvim https://github.com/Blizire/stiles.nvim.git
- zellij
- windows terminal
- alacritty
