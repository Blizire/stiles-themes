# zellij

To install this theme you will need to copy the themes folder and place it in
the location next to your config

```
# windows
~\AppData\Roaming\Zellij\config\

# linux/macos
~/.config/zellij/
```

After copying the themes folder edit your configuration so the theme has this
in it.

```
theme "stiles-dark-theme"
theme_dark "stiles-dark-theme"
theme_light "stiles-light-theme"
```
